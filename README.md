# Prompt Garden Community

Public community space for Prompt Garden submissions, prompt discussions, and field notes.

## How This Repository Is Used

- **Submissions**: use GitHub Discussions to share a prompt, an image, effect images, links, or a loose idea. Submissions are intentionally lightweight.
- **Prompt discussions**: Prompt Garden detail pages embed GitHub Discussions through Giscus so people can leave high-value feedback with a GitHub identity.
- **Curation**: accepted submissions are manually reviewed and curated into the private Prompt Garden content source. Nothing here is published automatically.

## Submit Something

Open a new submission discussion:

https://github.com/linshenkx/prompt-garden-community/discussions/new?category=ideas

You can submit one prompt, one image, a prompt with multiple effect images, or a loose idea that could become a reusable prompt.

GitHub currently stores the submission form under the `Ideas` category slug, so the URL uses `category=ideas`. In Prompt Garden operations, this category is treated as the public submission intake channel.

## Moderation

This repository is a wide intake channel with strict curation. Incomplete, unclear, duplicated, unsafe, or low-quality submissions may be closed or left unprocessed without follow-up.
